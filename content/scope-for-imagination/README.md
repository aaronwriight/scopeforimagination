# Generated Scope for Imagination content

Do not draft posts in this directory. The canonical author workflow and folder structure live in [`writing/README.md`](../../writing/README.md).

`pnpm writing publish TARGET` generates the website post and paired newsletter records here from the matching author folder under `writing/`. Edit the author metadata or source document, run review, and republish with `--replace` instead of changing generated JSON by hand.

The site reads published post records from `posts/`. Local records take precedence over a Sanity document with the same four-digit entry number.
